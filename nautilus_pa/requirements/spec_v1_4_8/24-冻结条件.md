### 3.1 原规格条款（迁移保留）

# 24. 冻结条件

V1.4.8 不应仅因代码可以运行就视为完成。

必须同时满足：

1. P0-A 至 P0-F 通过测试。
2. ProtectedLow 和 ProtectedHigh 生命周期可确定性复现。
3. 所有周期状态机通过人工黄金样本验收。
4. Zone 状态转换没有遗漏。
5. Setup 生命周期没有错误传播。
6. 15M 两类信号的触发 SwingPoint 可唯一确定；BREAKOUT 的 `trigger_swing_id` 为空，PULLBACK 的触发 SwingPoint ID 必填。
   6a. PULLBACK 的观察区位置校验只针对 PullbackLow；PullbackLow 更新时 TriggerSwingHigh 与 HigherLow 全部失效。
   6b. TriggerSwingHigh 最小反弹幅度参数、Zone 最小锚点 FIXED 约束和 Setup1H 宏观权限约束通过回归测试。
7. 3M 执行严格遵守 Signal 后确认和突破时序。
8. 3M 不产生独立方向或入场信号。
9. 回测不存在未来数据引用。
10. Bar 回测成交价格与订单时间约束一致。
11. 固定止损按实际成交均价重算。
12. 止损单只能从生效后的 Bar 开始触发。
13. 实际成交风险处置闭环完整。
14. REQUIRED 配置缺失时启动门禁有效，RESEARCH 参数实际值可追溯。
15. 成本模型、滑点模型和合约元数据版本可追溯。
16. 实际成交偏差检测、剩余订单撤销和风险预算联动闭环完整。
17. 部分成交后保护性止损数量不大于实际持仓数量。
18. 相同输入可以确定性复现。
    18a. ACTIVE Signal 的 `partially_filled` 能区分未成交与部分成交状态。
    18b. 风险恢复要求 1H 连续 3 根 BULLISH、4H 连续 2 根 TREND_UP；升级触发 Bar 不计数，从下一根完整 Bar 起算，计数中断立即重置。
    18c. 任意已成交 Signal 的剩余订单终止后必须进入 PARTIALLY_EXECUTED；EXPIRED/CANCELLED 仅允许零成交 Signal。
    18d. 所有 15M ATR 决策和止损计算均有明确快照来源；无效 ATR 不得计算倍数或静默替代。
    18e. 初始止损及部分成交后止损必须低于当前可执行退出价格，否则触发紧急退出/风险异常。
    18f. ExecutionRecord 保留全部 FillRecord，任一 Fill 的偏差超限不得被订单累计均价掩盖。
    18g. 风险预算减仓使用不含已发生入场费用的 CurrentRiskPerUnit。
    18h. CanOpen 与 CanHold 分离；风险恢复使用 CanHold，禁止以 CanOpen 替代持仓许可。
    18i. 每笔 Fill 独立审计，订单级最大单笔不利偏差不得被累计均价掩盖。
    18j. `initial_stop_atr_15m` 首笔成交后不可修改；每次止损更新必须保存 `stop_update_atr_15m`。
19. 随机片段测试使用有效初始状态快照。

完成以上条件后，才能冻结策略规格并进入完整策略回测阶段。

## 4. 数据与状态契约

### 4.1 失效传播表

| 失效事件 | 直接对象 | 下游传播 | 已成交仓位 | 新开仓约束 |
|---|---|---|---|---|
| 15M N 结构失效 | 绑定该结构的候选 | 旧 structure_id 终止，候选按生命周期失效 | PositionManager/RiskManager 执行结构退出规则 | 旧结构不得再生成 Signal |
| 4H/1H ProtectedLow 失效 | 周期转 TRANSITION | 活动 Setup INVALIDATED 并向子对象传播 | 风险升级；仅明确强制退出时平仓 | 禁止新开仓 |
| Zone BROKEN/INVALIDATED | 绑定该 Zone 的活动 Setup | Setup INVALIDATED；Signal 按自身失效条件处理 | 不隐式平仓 | 不依赖此 Zone 新建对象 |
| Setup EXPIRED | 当前 Setup | 子 Setup EXPIRED，不传播为 INVALIDATED | 不自动取消已有 Signal | 不再创建子对象 |
| Setup INVALIDATED | 当前 Setup | 子 Setup INVALIDATED；未成交 Signal 按规则终止 | PositionManager/RiskManager 按明确规则决策 | 禁止使用该父级 |
| CanOpen 变 False | 新 Signal/入场资格 | 禁止新增；已成交部分按执行状态管理 | 不自动平仓，独立判断 CanHold/ForcedExit | 冻结新开仓 |
| 订单/账户/保护异常 | 异常管理器 | 进入风险异常状态机 | 紧急退出并对账 | 未处置期间冻结并持续告警 |

### 4.2 风险异常处置状态机

| 状态 | 含义 | 后继状态/条件 |
|---|---|---|
| NORMAL | 无待处理异常 | EXIT_PENDING 或 RECONCILIATION_PENDING |
| EXIT_PENDING | 紧急退出已提交、尚未确认全平 | RECONCILIATION_PENDING；无法自动保证安全则 MANUAL_INTERVENTION_REQUIRED |
| RECONCILIATION_PENDING | 订单、持仓或账务差异待核对 | 差异消除且仓位合规转 RESOLVED；仍需退出转 EXIT_PENDING；需要人工则 MANUAL_INTERVENTION_REQUIRED |
| MANUAL_INTERVENTION_REQUIRED | 需要人工接管 | 人工完成后 RECONCILIATION_PENDING |
| RESOLVED | 异常已处置且对账完成 | 新异常周期转 NORMAL |

进入非 NORMAL 状态即冻结新开仓并告警；仅所有未平风险已处理、订单与账户对账完成后解除冻结。记录异常 ID、触发事件、订单/持仓 ID、请求/回报时间、成交、剩余数量、对账结果及人工操作审计。重试上限、退避与人工接管阈值见 [OD-03](./OPEN_DECISIONS.md#od-03-风险异常处置第-15-17-24-章)；确认前不得宣称自动处置完整，不得静默无限重试或解除冻结。
