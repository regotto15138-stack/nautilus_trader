## 7.1 人工标注必须前置

P1-A 状态机实现前，必须先完成冻结历史数据的人工标注。

- 1MONTH：UPTREND、WEAKENING、DOWNTREND、UNKNOWN。

- Bar 时间。
- 周期。
- 人工状态。
- 关键 SwingPoint。
- ProtectedLow。
- ProtectedHigh。
- PullbackOriginHigh。
- 状态转换原因。
- 标注版本。

### 3.3 修订补充：标注方法论与因果性（R1，优先于本章冲突的描述）

**规范边界：** 本节给出可实现的建议协议。涉及数据集范围、统计门槛、样本下限、复核责任人、Macro-F1 汇总方式的最终授权仍属于 `OD-05`；未冻结时 `P1-A=BLOCKED`。不得通过本章的示例值自动关闭 OD-05。

#### 3.3.1 先冻结规则、后标注、再实现（P0 #1、#11）

执行顺序：`P0-E: 冻结指标/时间/状态定义及 PB 预期 → OD-05: 批准标注手册、数据切分、标签体系、统计口径、阈值及责任人 → 锁定原始数据与哈希 → 标注员独立标注 → 仲裁并冻结黄金标签 → P1-A 状态机实现 → 盲测/验收`。OD-05 未关闭时只允许 **PILOT** 试标注，产物不可充当正式 P1-A 黄金集。若规则变化，必须提升 `label_policy_version` 并重新评估受影响样本，不得悄悄覆盖标签。

- 标注输入只能包括该 Bar 决策时刻已经完成且可用的本周期和高周期 Bar、已确认 Swing、保护点、Zone 快照；必须保存 `as_of_time`、`available_at` 和依赖快照版本。禁止依据未来涨跌、事后确认的 Swing 或算法预测标签来倒推人工真值。
- 标注员先按第 08/09 章已冻结的状态定义独立判定，记录状态、关键证据、相邻状态、转移原因和不确定性。**不得**以待验收状态机的输出作为标签来源；模型输出仅在标签冻结后做差异分析，以消除循环依赖。
- 每个 `(dataset_version, instrument_id, timeframe, bar_close_time, label_policy_version)` 唯一。两名独立标注员互不可见初始答案；不一致由指定仲裁人依证据裁定，保留双方原始记录、理由、仲裁结果与时间。仲裁人和最少标注人数由 OD-05 冻结；这里的双人流程是待批准建议。
- `UNKNOWN` 仅用于定义允许的不可判定状态，缺失数据用 `INSUFFICIENT_HISTORY` 等数据质量标记隔离，**不得**把无效输入一律标成 UNKNOWN 以提高准确率。`NOT_APPLICABLE` 不参与状态分类但必须计入覆盖率报告。
- 人工标签和算法输出均按同一决策截止时间对齐，`occurred_at` 不得替代 `confirmed_at`；事件的生效时间不得早于所有依赖输入的可用时间。

#### 3.3.2 数据切分、样本单元与防泄漏

- 样本单元为一个已完成且有效的 `(instrument, timeframe, close_time)`，每单元恰好一个人工状态和一个算法状态。相同 Bar 的多次回放只计一次；按 Bar 连续持续的状态不等于多个独立的状态转换事件。
- 训练/规则调参集、试标注集、冻结验收集按**时间区间**分割；同一市场事件在多个周期的重叠观察窗口应归入同一切分，设置不小于最大特征回看/确认窗口的 embargo，防止跨集泄漏。切分区间和 embargo 由 OD-05 冻结。
- 统计输出同时给出 Bar 级支持数、独立趋势/回撤 episode 数、转换事件数、覆盖的日历跨度、缺失数据比例；不可仅以大量连续 Bar 达到有效样本量门槛。
- 标签集必须覆盖正常连续数据、缺口、数据修订、边界时间、同一时刻多周期完成、重复 Bar、延迟确认 Swing 和相互冲突的上下文。

### 3.4 修订补充：验收指标精确定义（P0 #3）

#### 3.4.1 状态分类计数

对每个周期 `t` 和已冻结状态集合 `C_t`，仅在有效且有人工真值的评估 Bar 集合 `E_t` 上统计。对类别 `c`：

- `TP(t,c) = count(y_true=c AND y_pred=c)`；`FP(t,c) = count(y_true!=c AND y_pred=c)`；`FN(t,c) = count(y_true=c AND y_pred!=c)`。
- `Precision = TP/(TP+FP)`；`Recall = TP/(TP+FN)`；`F1 = 2TP/(2TP+FP+FN)`。
- 若类别在冻结验收集中 `support=TP+FN=0`，则标记 `NOT_EVALUABLE`，**不得**按 1.0 或 0.0 偷偷纳入 Macro-F1；该类别覆盖不足须独立触发门禁失败或 OD-05 明确豁免。若 support>0 但无任何预测，F1=0。
- `MacroF1(t) = mean(F1(t,c) for c in C_t)`，仅当所有必评类别满足样本下限且可评估时才定义；总体 `OverallMacroF1 = mean(MacroF1(t) for t in {1MONTH,1W,1D,4H,1H})` 为 **R1 建议的等周期权重口径**，最终由 OD-05 批准。禁止将所有 Bar 混合后计算一个微平均 F1 冒充 Macro-F1。
- 原文 `Overall Macro-F1 >=0.85` 和 `各状态 Recall >=0.80` 保留为**原始初始门槛**，正式分周期门槛、低样本豁免与统计区间必须在 OD-05 中冻结；任何周期或状态缺少足够样本，结果为 `INSUFFICIENT_EVIDENCE`，不能判定 PASS。

#### 3.4.2 状态转换事件与时间误差

- 真值转换：同一周期有效且连续的两个标注 Bar 状态不同，转换时间取新状态**首次可判定的已完成 Bar 的 close_time**。算法转换采用同口径；遇数据缺口时断开连续性，不跨缺口推断事件。
- 事件匹配按 `(instrument, timeframe, old_state, new_state)` 一致且时间偏差在该周期 `±1` 根已完成 Bar 内，按绝对偏差最小、时间最早、事件 ID 字典序的确定性顺序做**一对一**匹配；一条预测事件不能匹配多条真值事件。日/周/月用各自 Bar 序号差，不用固定小时数替代。
- `TransitionPrecision = matched_predicted / all_predicted`，`TransitionRecall = matched_truth / all_truth`，`TransitionF1 = 2PR/(P+R)`；原文“转换识别准确率 ≥90%”在 OD-05 冻结前**不擅自解释为其中任一指标**。R1 建议以 `TransitionF1 >=0.90` 并同时报告 P/R 和匹配时间误差分布作为替代候选。
- `±1 Bar` 是**已匹配事件**的时间容差，不是允许漏报；必须报告 `exact_match_rate`、`within_1_bar_rate`、延迟/提前方向、未匹配真值数和多报数。没有真值转换事件的集合不能自动判为 100% 正确。
- 置信区间应以独立 episode 或时间块为重采样单元，而不是将连续 Bar 当独立样本；OD-05 冻结置信水平与是否用于准入。

#### 3.4.3 分周期差异化门禁（P1 #6）

| 周期 | 样本约束 | 验收处理 |
|---|---|---|
| 1MONTH | 自然月数量少、转换稀疏 | 报告年月跨度、各状态月份数和独立转换数；不足则 `INSUFFICIENT_EVIDENCE`，不降低门槛假装通过 |
| 1W | 周线转换数可能少 | 以周 Bar 和独立事件双重报告；不足时扩展**预先批准**的历史区间 |
| 1D | 日线样本较多但时间相关 | 统计状态持续 episode 和跨行情覆盖 |
| 4H | 结构转换较密集 | 同时检验 RANGE/PULLBACK/TRANSITION 易混淆类别 |
| 1H | 状态更细、频繁转换 | 额外报告 REVERSAL_CANDIDATE 的 Precision/Recall |

各周期 `min_bars_per_class`、`min_transition_events`、`min_episodes`、可接受的置信区间和是否允许历史不足豁免均为 **OD-05 REQUIRED**。不可用临时样本扩容、随机重复抽样或降低门槛掩盖不足。若历史上根本无法形成充分 1MONTH 转换事件，应由 OD-05 明确限定验收结论的适用范围，并标记未验证状态，而非虚构通过。

### 3.7 修订补充：自动化阶段门禁（P1 #12）

验收流水线最少执行：`schema_validate → dataset_integrity → policy_freeze_check → label_audit → sample_sufficiency → classification_metrics → transition_matching → PB_phase_assertions → cross_timeframe_assertions → evidence_manifest → gate_decision`。任一必需依赖未冻结返回 `BLOCKED`，统计或断言不达标返回 `FAIL`，全部达标且审计齐备才 `PASS`；不可将 BLOCKED 视为测试成功。

`gate_decision` 输出机器可读 JSON（示意契约）：

```json
{
  "spec_id": "SPEC-V148-07",
  "phase": "P1-A",
  "status": "BLOCKED",
  "reasons": ["OD-05_NOT_FROZEN"],
  "dataset_hash": "<required actual hash>",
  "label_policy_version": "<required approved version>",
  "metric_policy_version": "<required approved version>",
  "per_timeframe_metrics": {},
  "transition_metrics": {},
  "pb_results": {},
  "evidence_manifest_hash": "<required actual hash>"
}
```

示例中的尖括号是待填写字段，不是可验收值。CI 应对 `FAIL` 和 `BLOCKED` 返回非零退出码；测试输出包括混淆矩阵、逐类 TP/FP/FN、分周期 F1、事件匹配明细、独立 episode 统计、人工仲裁记录、全部 PB 断言与配置/代码/数据哈希。每次冻结或重跑生成新的不可变证据清单，禁止修改旧报告。

### 3.8 其他审查修复与待决清单

1. **状态集不对称**：1MONTH、1W、1D、4H、1H 的枚举不同；采用逐周期独立混淆矩阵，禁止统一标签字符串的隐式转换。
2. **时间泄漏**：标签和模型均按数据可用时间对齐；未来确认的 Swing 不能回填过去 Bar。
3. **类别极度不均衡**：Macro-F1 与逐状态 Recall 双重门禁，补充每类支持数和 episode 数。
4. **转换事件一对多**：使用一对一匹配，报告未匹配事件。
5. **重复与缺失数据**：缺口不跨越推断转换；重复回放不重复计数。
6. **阶段错配**：P0-E 只冻结 PB 输入与预期；P1-A 评估 OD-05 与标注，P1-D、P2、P3 的执行用例必须在各自阶段单独验收。
7. **OD-05 必须冻结**：历史数据范围/哈希、标注手册版本、标签责任人、争议仲裁人、样本量下限、Macro-F1 权重与零分母规则、转换准确率的正式含义、时间容差、分周期门槛、CI 门禁清单。
