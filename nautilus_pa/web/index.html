使用说明 · 连续标注
  1. 选择周期，再在「标注工具」中选择 Swing、N 结构、Zone、保护点 或 状态区间。图层复选框只控制显示，不进入标注。
  2. Swing：点击发生 Bar，再点击确认 Bar；价格默认取该 Bar 的 High/Low。
  3. N 结构：依次选择 L1 → H1 → L2 → H2 四个已确认摆动点。
  4. Zone：选择至少两个同向摆动点；ANCHOR_ONLY 由后端算边界，HUMAN_BOUNDARY 填写人工 Lower/Upper/Center。
  5. 保护点：点击 Bar，选择 INIT / UPDATE / INVALIDATE；15M 独立 ProtectedLow 会被拒绝。
  6. 状态区间：选择状态后点击开始 Bar 和结束 Bar；保存 valid_from / valid_to / known_at。
  7. 点击待提交面板的「保存草稿」入库为 DRAFT；保存后可继续标注下一个。
  8. 已保存标注显示在「人工标注」图层；可删除未冻结标注或导出 JSON。
  9. 需要参与比对时，再把标注推进到 APPROVED，并点击「冻结黄金样本」；只有冻结后的 Ground Truth 才进入 Swing / Zone / N 结构差异比较与程序回放。
