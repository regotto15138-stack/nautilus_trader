# TASK_DEPENDENCIES — 依赖关系

> 权威来源：`tasks.json` 中每个任务的 `depends_on` 字段；本文件是可视化视图与批次级约束说明。
> 依赖成环会被 `validate_tasks.py` 拒绝。

上游产出是下游输入；跳过任一步，后续验收都不成立。

- B10b 与主线可并行（校准准备）。

阶段出口未满足，下一阶段任务不得进入 READY。

## 3. 依赖写法

    "depends_on": ["TASK-001"]

规则：
1. 只写直接前置，不写传递依赖（由链自动推出）。
2. 依赖的任务必须存在且未 CANCELLED。
3. 同一文件的写任务不能互不依赖地并行——`allowed_paths` 有交集一律串行依赖
   （本项目共用父仓库，不分分支、不建 worktree；见 D-007）。
4. 接口变更任务必须排在依赖该接口的实现任务之前。

## 4. 环检测

`validate_tasks.py` 用 DFS 三色标记检测环；发现环时输出具体路径并以非零码退出。
